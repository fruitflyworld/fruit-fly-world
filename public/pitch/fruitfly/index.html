01 / 一周

2026-09-15 到 09-20。判断层被教育完了。

TypeSafe AI 出潜发布 Jev，自称第一个 System One 模型。它不写字。读一段状态，返回 Noul / Choice / Score。市场用五天学会了这个品类。果蝇世界不用再解释「什么是判断层」，只要占住「判断层最硬的应用：活着」。

日期事件
09-15Jev 发布。HN 三天 1863 分、491 评论。BusinessWire 发 $40M 种子轮稿（DCVC 领投；Forbes 报道估值 $200M）。
09-16The Register / The Decoder 报 Doom demo。Browser Use 官方接入。
09-17Riley Brown 推文分析器。Matthew Berman：40 秒分析 724 条广告、8,724 次判断。jaredpalmer 发 Kev-0.5B。
09-18TechCrunch 长文。OpenJev 上 HN（693 分）后更名 SemIf。
09-19creativeainews：《六个克隆，四个 Jev 分数》。Bespoke Nimble 发布。
09-20LangChain 公开 Jev-as-a-Judge。X 累计曝光约 3700 万。

公司

CEO Diogo Almeida，前 OpenAI，RLHF / InstructGPT 共同发明人。核心赌注是全合成数据。Jev ← 杰文斯悖论；System One ← 卡尼曼。

可信的工程事实

仅文本/JSON。一次前向问完所有问题。第三方测 100 问与 3 问延迟几乎相同（714ms vs 712ms）。热连接 250–580ms。Doom demo 约 10 次/秒。

不可信 / 未验证

RLCD 无论文。193.6× / 444.6× 是自报，对的是强模型一致性不是真值。「零幻觉」只指类型安全——高置信判断照样会错，官方 FAQ 自己承认。

Forbes 的切入值得记住：他们修的是 AI 的过度自信。校准是公司级叙事，不只是模型特性。果蝇世界把校准从曲线变成「跳没跳过拍子」。

02 / 四派

八个项目。没有一个在做世界。

发布 48 小时内开源复刻按架构假设分裂——因为没人知道 Jev 的权重是什么。接口不难。难的是报 90% 的时候，这个 90% 有多可信。

项目派做法自报 / 边界
SemIf1 读分数现成 Qwen，在要答 A/B/C 时截住，只读选项分数再换算概率。不重新训练。最省事。作者自己说 softmax 不是校准置信度。
Simple Jev1 读分数同一段材料只读一次，后面多个问题共用前缀，再分别算答案概率。复刻接口和用法。不代表已做到 Jev 的准确率、速度、校准。
Laya2 专用模型放弃会写字的大模型，改用编码模型 + 决策头。几亿参数，很快。77 选项任务 42.5%，对照表里 Jev 87.0%。复杂任务差距明显。
Von2 专用模型~4 亿参数，不生成文字，一次前向处理 Choice / Noul / Score。本地 GPU 单次可压到几十毫秒。更像能读自然语言的分类器。
Verdict2 专用模型~1.5 亿参数。专门打两个洞：答错仍报高置信；A/B 换序答案跟着变。这条路线看重稳定，不看重会不会写诗。
Kev3 改造大模型给 Qwen 加决策结构，同一份输入只读一次。官方 SDK 改 base_url 就能打本地。新题 8B 约 78%，Jev 约 86%。路线能跑通，差距还在。
Nimble3 改造大模型Qwen3.5-9B + 「只改一个事实，正确答案就翻转」的后训练。324 个未参与训练样本 90.1% vs Jev 93.2%。概率尚未完全校准。H100 ~115ms。
OpenJev4 扩散填空DiffusionGemma。多个答案位置留空，一次填完，不逐 token 往后吐。RTX PRO 6000 上单请求中位约 94ms。
CAMP 1

直接读现成大模型的答案分数

SemIf、Simple Jev。冻结 Qwen，截 logits。最快做出「像 Jev 的 API」。

CAMP 2

重新训练专用决策模型

Laya、Von、Verdict。小、快，复杂任务和校准是硬伤。

CAMP 3

把现有大模型改造成决策模型

Kev、Nimble。保留 Qwen，加结构或做事实翻转后训练。最接近「把大模型变成脑干」。

CAMP 4

用扩散模型直接填答案

OpenJev。一次填多个槽。延迟叙事强，品类仍缺真值。

别人在复刻脑干。果蝇世界要做的是那只脑子住进去之后会不会死。

03 / 缺口

同一个 Jev，四个分数。这个品类没有标准基准。

creativeainews 09-19 拆过弹：Banking77 上四个独立评测，同一个闭源 API，分数从 87.0% 掉到 76.3%，散布 10.7 个点。@abacaj 在 Latent.Space 的原话被这一周证实了：demo 强调速度多于质量，品类没有标准基准。

静态评测测不到的三件事

无代价：答错只扣分。无闭环：答案不改变下一个输入。无竞争：没有别人抢同一口糖。培养皿三件都有——判断错 = 能量清零；每次判断改世界；存活率是相对值。

校准比准确率更硬

Arize：把 0.3–0.7 的中间带（占 4.6%）送人工，其余 99.5% 准确。judge-audit：对抗下准确率仍高，但平均置信度从 0.996 崩到 0.71——失败与低置信重合，闸门用得上。任务路由里却出现「自信地、系统地错」。准确率榜抓不到，只有校准审计抓得到。

对照数字钉死边界：冻结 bge-small + logistic 回归 + 10,003 条标注，Banking77 得 93.3%，反超 Jev 83.2%。有标注时监督小模型赢；Jev 的地盘是零样本 + 延迟。 果蝇世界每一局都在生产带生存标签的决策语料。死亡就是 Nimble 那种对比负样本，而且是真的。

04 / 现状

概念是对的。形态还像落地页，不像 Steam 游戏。

fruitfly.world 说「不要叫它说话，给它一个世界去生存」。这句话可以当工作室座右铭。但第一分钟的体验是：连接组、灵魂绑定、连钱包、等整点。Steam 游戏第一分钟要有手感、有失败、有再来一局。

做对了

FlyWire 2024：约 139,000 神经元、约 1500 万突触，最小但完整的脑子是真科学对象。四个信号 → 一个行为（靠近 / 躲开 / 乱逛 / 停住）透明可复现。纯函数回放（同种子同输入同结果）是最重要的资产，后面所有方案都不能破坏它。

做错了

门槛设反。没有死亡，路线错了只是分数低。AI 的用法是「COPY THE TASK 给大模型，把答案贴回来」——搜索，不是 agent。奖励是不能转让的护照。奖励应该是一只更会活的脑子。NPC 彩蝇不抢食。突变是噪声不是选择。

FLY LAB 已经证明 60 秒一代、三种驾驶、公开打分能玩。缺的是：突变改三选一、Agent 搬出控制台、真竞争、System One 真的在每 tick 判断。

05 / 游戏

果蝇版杀戮尖塔。脑干是 System One。

对玩家：90 秒一局，养一只会自己做决定的果蝇。对 agent 开发者：公开、可复现、有死亡的试炼场。对围观者：能看懂「AI 在做决定」的窗口——不是聊天框，是培养皿。

01 接线 · 15s

选性格

野生型均衡；贪吃鬼食物信号 ×2，为一口糖送命；惊弓之鸟危险权重 ×2，容易饿死；探险家被新鲜感驱动，前期弱。滑条保留——拖的是子回路输入增益，不是神秘权重。
02 放飞 · 60s

四个信号进脑干

食物（触角叶 → 蘑菇体 / 侧角）、危险（LPLC2/LC4 → 巨纤维逃命跳）、光线（中央复合体定向）、新鲜（蘑菇体：这味道见过没有）。玩家可干预：丢水果、挥拍子、暂停看概率。
03 结算 · 5s

死亡公开

分数 = 12×进食 + 40×探索% + 0.5×存活秒 + 40×逃命跳成功。死因：饿死 / 被拍死 / 活满全场。没有死亡就没有紧张感。
04 变异 · 10s

三选一，不是随机抖

嗅觉增强、巨纤维敏感、饥饿门控、记忆痕迹、节能代谢——每张牌有代价。卷翅更快但更耗能。「这一局我赌什么」就是游戏性。
fitness = 12×eaten + 40×explored% + 0.5×alive_s + 40×escape_jumps

三种驾驶，同一张榜

模式谁在决定给谁
基因自动感知权重 / FFW-CX 回路想摸生物学的玩家
手动人，WASD / 拖动想要手感的玩家
Agent粘贴 JS 策略，或托管任何 System One（Jev / Nimble / Kev / 本地）开发者。概率画在 HUD 上

培养皿里 3–5 只果蝇共享有限食物。杀它的不是环境，是别人的策略。排行榜按分数，标注这只蝇的脑是权重、人、还是哪个模型版本。

06 / 培养皿

拖四个信号。看脑干怎么选。

这是 HUD 原型。下面的概率来自与游戏同一套启发式：饥饿门控食物、逼近阴影走巨纤维、新鲜感驱动探索、能量低就冻结。换成 Jev 时，接口不变，只换那一次 POST /v1/systemone。

07 / 脑干

System 2 规划路线。System 1 开果蝇。

现在的「COPY THE TASK」是慢思考，每窗口一次，可以留着。缺的是战术层：每 tick 把培养皿状态发给任何 Jev 线兼容模型，Choice 回来直接执行。70–500ms 够 5–10Hz。输出免费，一局 600 次判断，成本几乎全在输入，量级不到一分钱。

state(food, threat, light, novelty, energy, t) → Choice(approach/avoid/explore/freeze) + Score(danger 0–3) + Noul(hunger_override)

游戏里直接用的问题包

{
  "act": {
    "type": "choice",
    "instructions": "Given four Drosophila-like signals and remaining energy, what should the fly do this tick?",
    "criteria": {
      "approach": "move toward the strongest food cue",
      "avoid": "escape the looming shadow — giant-fiber jump",
      "explore": "walk into cells not yet visited",
      "freeze": "hold still; metabolism first"
    }
  },
  "danger": {
    "type": "score",
    "instructions": "How close is death this tick?",
    "levels": {
      "0": "safe",
      "1": "uneasy",
      "2": "looming",
      "3": "jump now"
    }
  },
  "hunger_override": {
    "type": "noul",
    "instructions": "Is energy low enough that food should override novelty?"
  }
}

回放怎么做（硬约束）

Jev 是外部 oracle，版本会漂。竞赛窗口要求纯函数。解法：每次调用的 state、问题包、分布、置信度、模型版本全部落日志，带内容哈希。回放不重跑模型，只验日志。禁止 jev-latest，钉死 jev-1.13.0 或本地模型哈希。

后端可换

同一 schema 可打 TypeSafe、Kev（改 base_url）、Nimble、SemIf、或 FFW-CX 回路。无 key 时启发式兜底，HUD 写明 backend=fallback。判断层本身没有护城河，所以果蝇世界从不把核心循环押在一家供应商上。

Jev 在游戏里的三份工

当脑

玩家侧。每 tick Choice。概率画在头上。选错了能量清零——判断第一次有代价。

当裁判

平台侧。Noul：这条路线和声明的策略一致吗。高光检测：刚才是不是极限逃生。触发死亡回放。

当导演

世界侧。Score 评当前紧张度，调拍子刷新和食物密度。90 秒需要戏剧曲线。

08 / 连接组

科学声明写进页脚。滑条变成神经元输入电流。

默认脑不是 139k 神经元的全脑仿真。游戏循环用回路基序约束（T1），展示/研究模式再上脉冲子回路（T2）。FFW-CX/0.1 已经按这个诚实程度实现过：约 30 个神经元，每个基序有文献出处。

档内容能写进游戏的话
T0 现状手工四信号权重 FFW-CI/0.1connectome-inspired。最弱，人人能做。
T1 推荐真实回路拓扑约束决策骨架connectome-constrained。有逐突触引用。
T2 展示从 FlyWire 抽子回路跑确定性 LIFspiking subcircuit from FlyWire。可发方法学 note。
T3 不做NeuroMechFly 级全脑具身研究合作，不是游戏组件。

是真的

FlyWire（Dorkenwald et al. 2024, Nature）完成成年果蝇全脑接线。嗅觉寻食、阴影逃命（LPLC2/LC4 → DNp01）、饥饿放大食物信号（NPF-DAN，Beshel & Zhong 2013）、蘑菇体气味学习，都有文献。Shiu et al. 2024 证明 LIF + 连接组 + 递质符号能预测进食/梳理回路，并经光遗传验证。

是游戏化 · 不声称

性格是权重预设，变异是强化牌。不声称复刻完整大脑，不声称果蝇有意识，不声称这是科学仿真。透明比「看起来很真」更重要：每回合公开输入、决策、概率、结果、模型版本哈希。

三条硬约束：不能破坏纯函数回放；边列表 SHA-256 钉死随版本发布；滑条保留为解释层——拖食物 = 调 ORN 刺激强度。

09 / 为什么这比点按钮硬

点按钮可以撤销。培养皿里慢了就是死了。

别人拿 Jev 筛广告、清上下文、当裁判、点浏览器按钮。用完即走。我们拿它给一只会饿死的生物当脑干。分数、死亡、排行榜都是真的。这是判断层模型唯一自带地面真值的闭环生存测试场。

Benchmark

存活曲线、风险调整收益（贪吃鬼高分高死）、探索-利用、换图后的泛化。静态 eval 测不出这些。

校准试验场

模型说危险 3、置信 80%，影子落下它是不是 80% 活下来？可靠性图第一次有行为真值。低置信回退到基因本能，阈值能被测出来。

跨基质比较

人 vs 演化权重 vs System One vs 连接组控制器，同一只培养皿。最优觅食（MacArthur & Pianka 1966）和边际值定理第一次变成可玩的题。

数据飞轮：10Hz × 60 秒 × 每局 × 每个玩家 = (状态, 决策, 概率, 结果)。公开数据集满足可复现。数据训练更强的本地判断模型，再进游戏。Jev 是冷启动火箭，不是终点。

10 / 落地

先让它死得明白。再让它进化得像选择。

#做什么为什么是现在
1死亡 + 公开死因 + 90 秒短局没有死亡就还是落地页
2突变改三选一游戏性的核心决策感
3Agent 搬到页面：粘贴策略 + 托管模型普通人不会写 setControl

10分享 15 秒死亡回放每只死掉的果蝇都值得被看见

Token 如果要做

消耗口必须是游戏动作：孵化、买突变牌、高级窗口入场。产出必须是可验证行为：通过回放校验的回合。红线：不生息、不分红、不承诺收益。社交任务最差，易女巫。先声誉，后 token，参数用声誉阶段的数据校准。

风险怎么写进游戏

Jev 热度会退——任何判断模型都能当脑干，本地 Nimble / Kev / FFW-CX 都行。果蝇题材是钩子，卖点是 agent 第一次有死亡。被说伪科学：第 08 节的诚实声明进页脚。API 成本：输出免费 + 本地兜底。

愿景

当所有人都把 AI 养成更会说话的秘书，真正的 agent 时代还没开始。 Agent 不该住在对话框里，它该被扔进一个会饿死它的世界：有身体、有限的资源、旁边全是同样贪婪的代理人。 Jev 是它的脑干，培养皿是它的世界。未来衡量智能的，不再是它说得多好，而是它能和别的智能一起，活着。

给工作室的一句话：判断层会继续扎堆。果蝇世界只要把死亡、回放、和那四个信号做硬，这一周的所有克隆都会想来这只培养皿里测自己。
