00 / 先说人话

三个名词，讲完再往下。

判断模型 / Jev 是什么？
普通 AI（ChatGPT 这类）是"聊天模型"：你问一段话，它回一大段。 Jev 不聊天，只做选择题——你给它一个情况、几个选项，它告诉你选哪个、多有把握。 像一个人不解释，只伸手指一下："选 B，80% 把握。" 因为又快、又便宜、又干脆， 很多开发者拿它当机器人大脑里的"条件反射"。它由 TypeSafe AI 发布，接口标准叫 System One。
连接组 / Connectome 是什么？
就是大脑的完整线路图——哪个神经元连哪个神经元、连多强。果蝇的连接组已经被科学家完整画出来了： 大约 14 万个神经元、几千万条连线，每一条都有名字和编号。这意味着我们不必"猜"一个果蝇大脑， 可以照着真的抄。
脑干 / Giant Fiber 是什么？
果蝇脑子里有一根特别粗的神经纤维，叫巨纤维（Giant Fiber），相当于人的脑干：不思考， 只负责"有东西扑过来了→跳！"。两只"眼睛"（LC4 和 LPLC2 两组视觉神经元）把"影子转得多快、 长得多大"报告给它，电位攒够，它就下令逃命。我们的游戏里，这根回路是真做的。

02 / 为什么问答考卷不行

答题好的人，
不一定活得下来。

用个类比：招聘司机，你是给他一张交规笔试卷子，还是给他一辆车、一条山路？ 问答评测就是笔试卷。它有两个致命伤：

致命伤一：答错不疼

笔试里选错了，扣一分。真实世界里选错了——吃到有气味的食物，捕食者循味而来，你就死了，没有下一题。 判断的"代价"只有在闭环里才存在，问答给不了。

致命伤二：置信度会说谎

今年圈里最大的丑闻（judge-audit 事件）：有人给判断模型看对抗样本，它照样说得斩钉截铁—— 平均置信度从 0.996 崩到 0.71 才被发现不对。 高把握 ≠ 正确，只有让后果落下来，才知道它的把握值几个钱。

所以真正的考核应该是闭环的：判断 → 行为 → 世界改变 → 新的处境 → 再判断…… 一圈一圈转下去，活下来的判断才是好判断。这套东西，问答 benchmark 做不了，游戏天生就是。

03 / 我们的三层

果蝇神经元 + 判断层 + 世界，
各就各位。

BRAINSTEM · 脑干

真生物学的逃生回路

LC4（2,442 突触）+ LPLC2（1,366 突触）→ 巨纤维。照着真果蝇的连线写的脉冲神经元， 负责不需要思考的事：看到阴影扑来，充电，满了就跳。大脑选择，脑干起跳。

JUDGMENT · 判断层

可插拔的"选择题 AI"

接口按 System One（Jev）设计：状态进，四选一行为 + 置信度出。后端随便换—— 官方 Jev、免费的开源克隆（kev / NanoJev）、或内置本地启发式。不绑 API，不绑成本，不绑 token。

WORLD · 考场

代谢压力 + 捕食者 + 代际

糖是安全的，烂食物值钱但留气味引来捕食者。能量见底就死，死了换下一代。 判断的代价是真实的——这是问答考卷永远给不了的东西。

闭环：世界喂信号，脑干管反射，判断层管取舍，行为改变世界。没有哪一环可以靠背题通过。

为什么判断层要架在真回路上面，而不是直接开果蝇？因为生物学替我们解决了 "底盘"问题：反射、代谢、稀疏编码这些脏活累活交给脑干，判断层只回答真正需要判断的问题—— "这块值 38 点但有气味的烂食物，我现在这个血量，值得冒险吗？" 分层清楚了，考核才公平： 换任何一个判断模型进来，底盘完全一样，成绩才有可比性。

05 / 钉死的数字

我们最反潮流的一点：
数字不会变。

评测造假和复现失败是今年判断模型圈最大的丑闻（同一个模型在四个评测里分差 10.7 分）。 我们的做法是把数字钉进测试里：

100% vs 68%

对照实验：真实连线 vs 随机打乱的连线，各跑 200 次遭遇。真实连线逃生率 100%，打乱的只剩 68%。 这说明 LC4/LPLC2→GF 的连线真的有功能——打乱它，果蝇就死得更多。任何人任何机器跑，都是这两个数。

bit-identical

同一个种子，同一个输入序列，输出逐字节相同。回放不是重跑，是验证。判断层的每次调用 （状态、问题、概率、模型版本、哈希）全部落日志——将来基准提交的就是这份日志，作弊无处藏。

66 个测试守护这些数字。改坏任何一个，构建直接红。

07 / 诚实边界

我们没吹的部分。

  • 闭环基准（flyline-bench）正在建设中：先出游戏内的确定性验证和本地榜，再谈公开榜。不抢跑宣布。
  • 不接 token、不接支付、不绑任何一家模型厂商的 API。
