驾驶模式 · WHO'S DRIVING

三种模式共用同一套速度、能量与打分规则——人手速快慢、代码写得好不好,和基因权重一样,都在同一张表里排名。手动模式用方向键/WASD 或在培养皿上拖动来操控。

Agent 接管 · 控制台 API 文档 
切到"Agent 接管"后,在浏览器控制台里调用:
window.FlyLabAPI.getState()
  // 读取信号、位置、能量、剩余时间、食物与威胁坐标
window.FlyLabAPI.setControl({x, y})
  // 每帧给一个转向向量,自动归一化;约 0.5 秒不更新会回退到基因自动驾驶
window.FlyLabAPI.setGenes({food, threat, light, novelty, freeze, photo})
  // 直接改写策略权重
window.FlyLabAPI.setMode('auto' | 'manual' | 'agent')
  // 也可以用代码切换驾驶模式
